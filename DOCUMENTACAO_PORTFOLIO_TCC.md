# Apoio Solidário

## Tema
Sistema web para conectar pessoas em situação de necessidade com voluntários dispostos a oferecer apoio.

---

## Problema identificado
Muitas pessoas encontram dificuldades para pedir ajuda de forma organizada, rápida e transparente. Ao mesmo tempo, voluntários muitas vezes não têm uma ferramenta simples para acompanhar demandas e entrar em contato com quem precisa de assistência.

---

## Proposta
Desenvolver uma plataforma digital que facilite a comunicação entre solicitantes e voluntários, promovendo apoio comunitário de forma estruturada e acessível.

---

## Objetivos

### Objetivo geral
Criar uma aplicação web que permita a conexão entre pessoas que precisam de ajuda e voluntários, com fluxo claro de solicitação, aceite, acompanhamento e comunicação.

### Objetivos específicos
- permitir cadastro de usuários com perfis distintos
- viabilizar a criação de pedidos de ajuda
- permitir a aceitação desses pedidos por voluntários
- acompanhar o status do pedido em tempo real
- possibilitar comunicação entre as partes envolvidas
- registrar notificações e histórico de ações
- melhorar a experiência do usuário com interface clara e funcional

---

## Metodologia
O projeto foi desenvolvido com abordagem prática e iterativa. A solução foi construída em etapas:

1. análise das necessidades do usuário
2. definição dos perfis e regras de negócio
3. implementação do backend em Flask
4. criação da interface web
5. validação do fluxo principal
6. ajustes de UX e regras do sistema

---

## Tecnologias utilizadas
- Python
- Flask
- SQLite
- HTML
- JavaScript
- Tailwind CSS
- Leaflet

---

## Funcionalidades implementadas
- cadastro e login
- perfil de solicitante e voluntário
- criação de pedidos de ajuda
- filtro e listagem de pedidos
- aceite de pedido pelo voluntário
- atualização de status do atendimento
- mensagens internas entre as partes
- notificações automáticas
- histórico de eventos
- cancelamento com motivo justificativo
- registro de localização

---

## Relevância do projeto
O projeto tem relevância social, tecnológica e educacional, pois:
- promove solidariedade e apoio comunitário
- utiliza tecnologia para solucionar um problema real
- demonstra lógica de desenvolvimento de sistemas web
- integra frontend, backend, banco de dados e UX

---

## Resultados esperados
A aplicação busca:
- reduzir a dificuldade de comunicação entre quem precisa e quem pode ajudar
- tornar o processo mais claro e organizado
- aumentar a confiança no atendimento
- facilitar o acompanhamento das demandas

---

## Contribuição acadêmica
Este projeto pode ser apresentado como uma solução voltada a inclusão social e apoio comunitário, mostrando a aplicação prática de desenvolvimento web em um tema com impacto real na sociedade.

---

## Conclusão
Apoio Solidário representa uma proposta funcional de plataforma para conectar ajuda e solidariedade por meio da tecnologia. O sistema combina boa experiência de uso, regras de negócio e uma solução relevante para atender necessidades reais da comunidade.
